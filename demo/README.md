# Demo generators

These scripts generate the mock previews, GIFs and SVGs used during development. They are not part of the plugin build, and the READMEs do not use their output.

The committed `*.live.*` assets are captured from a real Obsidian window in light theme. They are not generated by these scripts. The mock files are generated locally on demand and ignored by git.

## Requirements

The capture script uses Playwright, `pngjs` and `gif-encoder-2`. They are intentionally not part of the plugin's dependencies; install them temporarily:

```sh
npm install --no-save playwright pngjs gif-encoder-2
npx playwright install chromium
```

## Generate

```sh
node demo/capture.mjs   # PNG previews + animated GIF
node demo/make-svg.mjs  # vector infographics
```

The scripts write these mock files to `assets/` (generated locally, git-ignored):

- `kitchenforge-demo.png` — English mock preview
- `kitchenforge-demo.fr.png` — French mock preview
- `kitchenforge-demo.gif` — English calculation-mode animation
- `kitchenforge-demo.fr.gif` — French calculation-mode animation
- `kitchenforge-demo.svg` — English vector infographic
- `kitchenforge-demo.fr.svg` — French vector infographic

The READMEs use only these committed live assets:

- `kitchenforge-demo.live.png` — English live Obsidian screenshot
- `kitchenforge-demo.live.gif` — English live Obsidian animation, both modes
- `kitchenforge-demo.live.fr.png` — French live Obsidian screenshot
- `kitchenforge-demo.live.fr.gif` — French live Obsidian animation, both modes

`capture.mjs` deletes its temporary `demo/.frames/` directory by default. Set `KEEP_FRAMES=1` to keep the individual frames.
